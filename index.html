Работа вдвоём

Один репозиторий — общие записи. Каждый подключается со своим GitHub-токеном и отправляет изменения, когда готов поделиться правками.

Токен хранится только в памяти вкладки и отправляется только в api.github.com. После перезагрузки его нужно ввести снова. Не добавляйте его в файлы проекта.

Как подключить вас обоих
  1. Владелец репозитория добавляет друга: Settings → Collaborators.
  2. Владелец создаёт fine-grained token для этого репозитория с разрешением Contents → Read and write.
  3. Друг, добавленный как Collaborator в публичный репозиторий, использует свой Personal access token (classic) с областью public_repo. У этого токена доступ шире одного репозитория; задайте короткий срок действия. Для аккаунтов без ограничений fine-grained используйте токен только нужного репозитория. Подробности — в README.
  4. Укажите здесь одинаковый репозиторий и ветку. Каждый вводит свой токен.

Публичный репозиторий и опубликованный GitHub Pages видны другим. Не записывайте сюда секреты.

Есть разные версии

Вы оба изменили одну запись. Выберите, какую версию оставить. Остальные записи объединятся автоматически.
