# Общий блокнот по игре без аккаунтов GitHub

Готовая работающая версия: https://game-notes-duo.lowolfol.chatgpt.site/

Откройте её, нажмите «Создать общий блокнот» и отправьте другу полную ссылку из «Поделиться». Оба можете писать без регистрации. У каждого, кто знает ссылку, есть право чтения и редактирования. Сохраните её в закладках.

## Как выложить этот архив на GitHub Pages

1. Загрузите содержимое папки game-notes в корень публичного репозитория. index.html должен быть в корне.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Откройте опубликованный сайт и создайте общий блокнот.
4. Отправьте другу полную ссылку, включая #room=... . Не нужно добавлять друга в Collaborators или создавать для него GitHub-аккаунт.

В config.js уже указан работающий сервер общих записей. GitHub Pages раздаёт только интерфейс, а записи сохраняются на отдельном сервере. Если сервер станет недоступен, общая синхронизация остановится; локальные черновики и скачивание копии останутся доступны.

## Как редактировать

Нажмите на заголовок или текст и пишите. Через 1,2 секунды после ввода запускается автосохранение. Новые записи друга проверяются каждые 5 секунд в активной вкладке. Это совместная работа над записями, а не одновременное объединение набора текста по символам, как в Google Docs.

Если одновременно изменить одну запись, появится выбор версий. Правки разных записей объединяются автоматически. При потере соединения черновики остаются в браузере до успешной отправки. Не очищайте данные сайта до сохранения. Работайте в одной вкладке на устройство.

Имя для подписи можно указать в окне «Поделиться» — это не учётная запись.

## Если уже были записи в предыдущей версии

В старом сайте нажмите «Скачать копию». В новом общем блокноте выберите «Загрузить копию». Общие изменения теперь хранятся в серверной базе: заменять data.json вручную не нужно. Этот файл используется только как пример начального наполнения.

## Файлы

index.html — один лист заметок.
styles.css — оформление.
app.js — редактирование, автосохранение и совместная работа.
core.mjs — проверка данных и объединение правок (сохранена совместимость старого формата).
config.js — адрес сервера общих записей.
data.json — демонстрационные начальные записи.

Серверная часть опубликована отдельно. Этот архив предназначен для GitHub Pages, сам по себе он не разворачивает сервер и базу данных.


## Фотографии и закреплённая кнопка

Кнопка «＋ Запись» закреплена справа внизу экрана, в том числе на телефоне. Под каждой записью есть «＋ Фото». Можно выбрать несколько JPG, PNG или WebP: до 8 фотографий на запись. Перед отправкой фото уменьшается до 1600 пикселей по длинной стороне и сжимается в JPEG. Исходный файл допускается до 20 МБ; результат — до 2 МБ.

Файлы хранятся отдельно от текста, в серверном объектном хранилище. Они загружаются только по ключу вашего общего блокнота. На сайт и в GitHub не добавляются токены и секреты. При удалении фотографии из записи удаляется её привязка; исходный файл физически не удаляется, чтобы избежать потери при конфликтующих правках.

«Скачать копию» включает текст и фотографии в один JSON-файл. Новая версия умеет восстановить такую копию в другой блокнот. Старые JSON-копии без фото также поддерживаются. JSON из первоначальной версии, где есть только ссылки на фото, не переносит сами файлы между разными комнатами — для переноса используйте новую полную копию.

Для обновления замените app.js, core.mjs, styles.css, index.html и добавьте photos.mjs. Существующие data.json и config.js заменять не нужно. Ваши интервалы синхронизации в app.js сохранены. Общие записи в базе не очищаются.
